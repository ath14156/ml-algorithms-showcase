# 🤖 Machine Learning Algorithms Showcase

An interactive Machine Learning dashboard built with **Python, Streamlit, and Scikit-learn** that demonstrates **18 machine learning algorithms** across supervised and unsupervised learning.

The project provides interactive visualizations, adjustable model parameters, mathematical concepts, performance metrics, dataset previews, and real-world applications.

---

## 🚀 Features

- 18 Machine Learning algorithms
- Interactive Streamlit dashboard
- Adjustable model parameters
- Mathematical explanations
- Model evaluation metrics
- Interactive visualizations
- Dataset previews
- Prediction examples
- Real-world applications
- Supervised and unsupervised learning
